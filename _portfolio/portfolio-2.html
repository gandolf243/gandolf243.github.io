--- sitemap: true title: "Installer Resource Extractor" excerpt: "A Python utility for extracting system resources from macOS Big Sur and newer installers." collection: portfolio --- Installer Resource Extractor makes it possible to retrieve macOS system resources from installer packages without installing that version of macOS. It supports installers from Big Sur through Tahoe, with additional versions under consideration.
